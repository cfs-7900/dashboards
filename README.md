# Dashboards

Central repository for all interactive dashboards used by Camelot Facilities Services (CFS).

This repository serves as the public hosting location for self-contained HTML dashboards published through GitHub Pages.

---

# Purpose

This repository is intended to:

- Host interactive dashboards
- Provide visual reporting tools
- Store dashboard source files
- Publish dashboards through GitHub Pages
- Create a centralized dashboard library
