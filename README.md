# Dashboards

Central repository for all interactive dashboards used by Camelot Facilities Services (CFS).

This repository serves as the public hosting location for self-contained HTML dashboards published through GitHub Pages.

---

# Purpose

This repository is intended to:

- Host interactive dashboards
- Provide visual reporting tools
- Store dashboard source files
- Publish dashboards through GitHub Pages
- Create a centralized dashboard library

All dashboards should be:

- Self-contained HTML files
- No server required
- No database required
- Mobile-friendly when possible
- Easy to share with stakeholders

# Dashboard Standards

All dashboards should:

## File Naming

Format:

dashboard-[topic]-[year].html

Examples:

dashboard-hvac-asset-costs-2026.html

dashboard-work-orders-2026.html

dashboard-budget-analysis-2026.html

dashboard-vendor-performance-2026.html

---

## Design Requirements

- Single HTML file
- Self-contained
- No backend
- Responsive layout
- Clean executive reporting style
- Fast loading
- Shareable by URL

---

## Data Sources

Typical sources include:

- CSV files
- Excel exports
- Yardi exports
- Maintenance Connection exports
- Angus reports
- Vendor reports
- Internal trackers

# Publishing Process

1. Create dashboard HTML
2. Test locally
3. Upload to repository
4. Commit changes
5. Push to GitHub
6. GitHub Pages automatically publishes

Example:

https://cfs-7900.github.io/dashboards/dashboard-example.html
